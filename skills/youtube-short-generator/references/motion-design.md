# ロング解説のモーション設計

2026-10-30作成。横型16:9のロング解説と、必要な範囲で縦型Shortsに使う。参考「最高の老後」型の映像は、フルアニメではなく、フラット2Dベクターの場景に限定的な動きを足すモーショングラフィックスとして扱う。制作方法の分析は [動画の出典と素材](../../../sources/sources.md#参考チャンネル最高の老後の制作方式分析2026-10-17) を参照する。

## 目的

- 動きで理解を助ける。何を見るか、どこが変わったか、どの順序で読むかを示す。
- 動きで画面を埋めない。読む時間、間、余白を残す。
- 参考動画の見た目をコピーせず、動きの種類・密度・テンポだけを参考にする。
- Remotionのフレーム計算で再現できる形にする。ランダム、実時間タイマー、外部状態に依存させない。

## 基本原則

1. **1場景1目的**。場景ごとに、視聴者に一つだけ理解してほしいことを決める。
2. **主要な動きは同時に一つ**。カメラ、オブジェクト、ラベル、キャラを全部同時に動かさない。
3. **動かした後は止める**。文字・ラベル・図を出したら、読むための保持時間を置く。
4. **字幕を邪魔しない**。字幕表示中は、字幕帯の上で大きな動きをしない。
5. **カットを基本**。場景転換はカット。フェードは必要な場合だけ0.2秒以内。
6. **同じ型を繰り返す**。場景ごとに新しい演出を発明せず、移動・出現・ラベル・スタンプの組合せで作る。
7. **動きの意味を言える**。何のために動くのか説明できない動きは削る。
8. **背景は原則として静置する**。場景あたり1回のカメラ移動だけを例外とし、背景自体を常時動かさない。

## モーション予算

6〜8秒の場景を基本単位とする。

| 要素 | 目安 | 補足 |
|---|---|---|
| カメラ移動 | 1回 | プッシュインまたはパン。同時に両方しない |
| オブジェクト出現 | 2〜4回 | 部品、カード、図形、写真枠 |
| ラベル表示 | 1〜2群 | 1群2〜4個。0.08〜0.12秒ずつずらす |
| キャラの反応 | 1回 | 指差し、うなずき、瞬き、視線 |
| スタンプ・強調 | 0〜1回 | 決定・終・重要。乱用しない |
| 保持 | 1〜2秒 | 文字・図を出した後、次の動きまで止める |

場景が短い場合は要素を減らす。尺が足りないからといって、動きの速度を上げて詰め込まない。

## 動きの語彙

数値は実装の初期値。参考GIFから実測した値ではなく、パイロットで調整する。

| 動き | 実装 | 初期値 | 用途 |
|---|---|---|---|
| カメラ・プッシュイン | `interpolate` + `Easing.out(Easing.cubic)` | 100→104〜108%、0.8〜1.5秒 | 場景の導入、注目 |
| カメラ・パン | `interpolate` | 2〜4%、0.8秒 | 横長の図解、背景の見回し |
| オブジェクト出現 | `spring` | 0.25〜0.4秒、damping 12〜18 | 部品、カード、機械 |
| ラベル・ポップ | `spring` + stagger | 0.2〜0.3秒、0.08〜0.12秒ずらし | 部品名、注記 |
| スタンプ | `spring` + scale | 0.15〜0.25秒、1回 | 決定、終、重要 |
| 脱色／再着色 | `interpolate` color/filter | 0.3〜0.5秒 | 過去→現在、比較 |
| 線を引く | `strokeDashoffset` | 0.4〜0.8秒 | 経路、接続、矢印 |
| キャラ瞬き | フレーム周期 | 3〜5秒間隔 | 静止の自然さ |
| 指差し・うなずき | 差分パーツ or transform | 0.3秒、保持1秒 | 会話の反応 |
| カット | `Sequence` の切替 | 0フレーム | 場景転換 |
| フェード | `interpolate` opacity | 0.2秒以内 | 必要な場合だけ |

## 場景の基本構成

1. **確立**（0.0〜0.4秒）：背景・人物・主要オブジェクトを見せる。大きな動きはまだ付けない。
2. **焦点**（0.4〜1.2秒）：カメラを寄せる、または人物が指差す。視聴者の視線を一つに集める。
3. **展開**（1.2〜3.5秒）：部品・図・ラベルを順に出す。動きは一つずつ。
4. **保持**（3.5〜5.0秒）：字幕と図を読ませる。動きを止める。
5. **転換**（5.0〜6.0秒）：次の場景へカット。必要な場合だけ短いフェード。

尺は例。ナレーションの実尺に合わせて、保持を優先して伸縮する。

## カメラ

- プッシュインは最大8%。それ以上は画面が落ち着かない。
- パンは最大4%。端の文字・人物を切らない。
- カメラ移動の中心は、字幕帯と章バッジを避ける。
- カメラ移動中に新しい字幕を出さない。移動が止まってから字幕を出す。
- 画面全体を常時揺らさない。手持ち風、呼吸、ズーム反動は標準にしない。

## キャラクター

- 参考動画の人物は、毎回同じデザインで、動きは限定的。フルアニメの歩行・走行・複雑な身振りを標準にしない。
- 使う動きは、瞬き、視線、うなずき、指差し、小さな体重移動、腕の角度変更程度。
- 同じポーズを長く見せるときは、瞬きと小さな視線変更で止まって見せない。
- キャラの動きで説明を代用しない。説明は図・ラベル・字幕で行う。
- キャラ素材の正本は `../knowledge-anime-character-system/`。動画側で造形を変更しない。不足するポーズは不足として記録する。

## 図解・オブジェクト

- 部品は「分解 → ラベル → 組み立て」の順に見せる。最初から全部を完成状態で置かない。
- ラベルは対象の近くに置き、線や矢印で結ぶ。画面の端にまとめて置かない。
- 数値・年号・単位は算用数字。字幕・図解・見出しで表記を揃える。
- グラフは既存の `ToyotaV3Chart.tsx`、断面は `ToyotaTHSCutaway.tsx`、走行図は `ToyotaHybridDriving.tsx`、回生は `ToyotaPriusRegeneration.tsx` を優先して再利用する。
- 新しい図は、既存の線幅・色・角丸・フォントに合わせる。図ごとにデザインを変えない。
- 事実と模式図を区別する。模式図には注記を付ける。

## 字幕・音声との同期

- 字幕は下部帯。話者chipは既存仕様に従う。
- 動きの開始は、ナレーションの該当語が始まる0.1〜0.2秒前を目安にする。音より先に動きすぎない。
- 字幕が出ている間は、字幕帯の上でオブジェクトを動かさない。必要な場合は字幕の外側で小さく動かす。
- 音声の実尺が変わったら、場景秒・字幕・動きの開始を同じ定義で直す。
- BGM・効果音は権利確認済みのものだけ。動きに合わせて効果音を増やしすぎない。

## Remotion実装

- `useCurrentFrame()` と `interpolate()` / `spring()` を使う。`setTimeout`、`Date.now()`、`Math.random()` に依存しない。
- 複数の場景は `Sequence` で分ける。場景ごとに開始フレームを固定する。
- カメラは `transform: scale() translate()` で作る。レイアウトを動かさず、背景・人物・図を同じ座標系で動かす。
- 出現は `opacity` + `translateY` + `scale` の組合せ。`spring` の過剰な跳ね返りは避ける。
- ラベルのstaggerは配列のindexから計算する。ランダム順にしない。
- 文字は `AbsoluteFill` の上に置き、字幕・章バッジ・年バッジと重ならないようにする。
- 同じ動きを複数場景で使う場合は、小さな関数またはコンポーネントにまとめる。場景ごとにコピーしない。
- 既存の `LongformToyota01V11.tsx` の字幕・章UI・背景・人物配置を基準にする。新しいCompositionを増やす場合は、対象版recordへ理由と所有を記録する。

## 禁止・避ける動き

- 画面全体の常時回転、常時揺れ、呼吸のような拡縮。
- 文字の連続拡大縮小、蛍光色の点滅、過剰なグリッチ。
- すべての要素が同時に動く場景。
- 字幕の上を横切るオブジェクト、字幕と重なるラベル。
- 読む時間を削る高速な連続カット。
- 参考動画のカメラワーク・効果音・テロップをそのままコピーすること。
- 動きのためだけに事実・数値・条件を追加すること。

## 受入・確認

- 変更した場景の代表フレームを0.2秒間隔で確認する。開始・中間・終了だけで済ませない。
- 文字切れ、字幕との干渉、ラベルの読みやすさ、人物の見切れ、色のコントラストを確認する。
- 同じフレームを再レンダーして、動きが再現するか確認する。
- 連続再生で、動きが速すぎないか、保持が足りるかを見る。静止画だけで合格にしない。
- 動きの受入は [video-acceptance](../../../.agents/skills/video-acceptance/SKILL.md) と案件のPM受入に従う。技術検査の合格を、内容・聴感・本人受入の代わりにしない。

## パイロット

最初から全編を作らない。15〜30秒の1場景で、次を確認する。

- 背景1枚、人物2人、部品図1つ、ラベル3つ、字幕1〜2行。
- カメラのプッシュイン1回、オブジェクト出現2〜3回、ラベルstagger1群、キャラの指差し1回。
- 出力は場景単独のstillまたはMP4。全編レンダーは本人の明示指示まで行わない。
- 参考GIFと並べ、動きの密度・読みやすさ・制作時間を確認する。合格後に章単位へ展開する。

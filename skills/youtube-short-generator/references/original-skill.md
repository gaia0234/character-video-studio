# 縦型解説動画を制作する

作業ルートはこのSKILL.mdのあるフォルダ。実行コマンド・編集箇所は [README.md](README.md)、台本は [src/data/video.json](src/data/video.json)、根拠と素材管理は [sources/sources.md](sources/sources.md) を読む。

- 1080×1920、30fpsを初期値とし、尺はJSONのシーン秒数から計算する。画面右側・下側は投稿UIに重なるため、重要な文字・顔を端へ配置しない。投稿先の実表示で確認する。
- ルーノは説明・案内、ミーノは疑問・発見、カーノは分析・整理。台本は1本1テーマ・1つの結論を基本に、字幕と図解だけでも話が伝わるようにする。
- `RankingScene` は番号付きの説明にも使える。数値ランキングとして公開する場合は評価基準・対象・期間と根拠を記録する。根拠のない順位を付けない。
- キャラ正本は `../knowledge-anime-character-system/`。動画には使用版をコピーし、`public/assets/manifest.json` に参照元・版・SHA-256・承認状態を記録する。未承認の案を正式素材へ昇格しない。
- 音声・BGMは実ファイルと尺を確認してから配置する。提供元・利用条件・クレジットを出典ファイルへ記録する。動画制作を依頼されるまで台本・仮音声・試作動画を作らない。
- Reactの通常の時間・乱数で動かさず、Remotionのフレームから演出を計算する。静止画と書き出しで同じ描画になるようにする。
- 編集後は `npm run check`、該当カットの静止画確認、変更を含む動画の書き出しを行う。実行できなかった確認は未確認と報告する。字幕の欠け、数字、キャラの形、音声同期を確認する。

公開・投稿は動画制作と別の操作。ユーザーから依頼された範囲で進める。

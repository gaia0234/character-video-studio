# ランキングとN選の動画を作る

ランキングか並列紹介か、紹介するもの、短いコメント、画像を受け取り、1080×1920の縦動画を書き出す。毎回変更する内容を小さなJSONに置き、デザインと動きはRemotionのコンポーネントにまとめる。

このスキルは今回のShorts向け紹介デザインに絞った簡易版。最初に動く動画を作り、参考動画がある場合は、その見た目と動きに合わせて調整する。

## 受け取る内容

- タイトルを4〜5行に分けたもの。
- 紹介形式と3項目以上の内容。ランキングは順位の低い順、並列紹介は見せたい順。各項目は名前、画像、短いコメント1〜2個。
- 最後に出す一言。
- 任意で参考動画、ナレーション音声、BGM。

ゆっくり音声を指定された場合は、導入済みのAquesTalk等の環境を確認して使う。今回のような早めのランキングなら、f1（霊夢系）をタイトル・順位・青コメント、f2（魔理沙系）をピンクコメントに割り当て、話速160を初期値にする。音声を別の声で代用したまま完成とは扱わない。AquesTalkは会社・商用での利用に使用ライセンスが必要なので、既存の契約・利用環境に合わせる。

新作は最低3項目、通常は3か5にする。`presentation: "ranking"`（省略時）ならTOP Nと第N位を表示し、N→1で進める。`presentation: "list"` ならN選と1/N〜N/Nを表示し、1→Nで進める。並列紹介は音声も「ひとつめ」「ふたつめ」にし、「第1位」や人気順の表現を使わない。形式未指定はTOP3、順位なしで数が未指定なら5選。数字は入力項目数から求める。

販売数などの客観ランキングは、集計元と集計時点を確認する。根拠がない売上や投票順位を創作しない。独自の選定ならその旨を出典メモへ残す。

ネタは2ch・5ch・なんJ・なんG系で実際に読める話題や感想から優先して探す。URL・日時・板を記録し、まとめ経由と直接閲覧を区別する。まとめサイト名だけで全投稿をなんJの発言と断定しない。反応を短く要約し、存在しない投稿者・発言・集計順位は作らない。作品のあらすじや商品の機能は公式情報で補い、独自選定はキャプション・出典メモへ残す。

画像は実際のネット画像や提供素材を基本にする。公式の作品画像・商品写真などの取得元と利用条件を確認する。適した素材がない箇所や概念図は必要に応じて画像生成で補い、実物写真と生成イメージを区別する。Image2.5などの指定があれば利用できる環境を確かめる。生成なしの指示を優先する。主役の実画像は無関係なアイコンへ置き換えない。

## 最小の入力例

```json
{
  "presentation": "ranking",
  "title": ["週末に", "じっくり", "楽しみたい", "ゲーム紹介"],
  "ending": ["次はどんな", "ゲームで", "作ってみる？"],
  "introIcon": "gamepad",
  "items": [
    {
      "name": "紹介したいゲームA",
      "image": "game-a.png",
      "comments": ["魅力を短く\n2〜3行で書く", "遊んだ時の感想を\nひと言添える"],
      "seconds": 5.5
    },
    {
      "name": "紹介したいゲームB",
      "image": "game-b.png",
      "comments": ["別の魅力を\nここに書く", "ひと言コメント"],
      "seconds": 5.5
    },
    {
      "name": "紹介したいゲームC",
      "image": "game-c.png",
      "comments": ["一番伝えたい\nポイントを書く", "最後のひと言"],
      "seconds": 5.5
    }
  ]
}
```

上の例はTOP3。`presentation` を `list` に変えると同じ3件で順位なしの3選になる。5選は `list` で5件を用意する。導入文を別指定した場合も、TOPとN選の表現を形式に合わせる。

`image`は`public/`内のファイル名。ダウンロードや画像生成は準備工程で済ませる。動画を書き出すたびに外部画像を取得する構成にはしない。`seconds`は1項目の尺。ナレーションがある場合は音声の長さを測り、コメントの切り替えと尺を合わせる。

`introIcon`はゲームなら`gamepad`、アニメなら`tv`、不要なら`none`。図形はSVGで作り、同じ進入の動きを適用する。本番動画は制作メモや音声名の表示を初期状態でオフにする。出典と声の情報は別ファイルに残す。`selectionNote`などの確認用注記は、レビューで必要な場合だけ表示できるようにする。素材の顔がコメントに隠れる場合は、その項目だけ`imageMaxHeight`を小さくできるようにする。

## デザインの基準

### 画面と背景

- 1080×1920、30fps。背景は全面に表示。
- 明るいオレンジ`#F0AD3B`と濃いオレンジ`#E99627`で放射模様を作る。
- 中心は画面中央。43本程度の放射線をSVGの三角形で描く。線に約2pxのぼかしを入れる。
- 背景はゆっくり時計回りに回す。簡易版の初期値は毎秒5度。画面端が欠けないよう、三角形は画面外まで十分長くする。
- 主役は文字と画像。余計な粒子、装飾、角丸のUI、トランジションは加えない。

### タイトルと順位

- 日本語の太いゴシック。初期値はNoto Sans JPの900。
- タイトルは4〜5行。上の1行だけ白、残りは上が赤・下が黒のグラデーション。
- グラデーションは上から約38%まで赤`#FF0000`、約80%で黒。
- 赤黒文字の周囲に白16px、さらに黒38px程度の縁取り。外側に柔らかい黒い影。
- 文字・縁取り・影は同じ座標を共有する。文字幅の調整は共通の親要素で行い、静止画だけでなく連続レンダーでも重なりが崩れないか見る。
- タイトルは中央揃え。文字の塊が横幅の75〜90%を占めるように調整する。
- 下に黄色の`TOP N`（ランキング）または`N選`（並列）と、テーマに合うゲーム機またはテレビのイラストを置く。数字は項目数から出す。
- 画面上部の番号はランキングで「第N位」、並列紹介で「1/N」。だいたいy=150〜365に収める。
- 順位の下にゲーム名を白字と黒い影で出す。長い名前は2行。最初のコメントが出たら名前を消す。

### 画像とコメント

- 横長画像は画面の横幅いっぱいに表示し、下端はy=1750〜1800付近へ揃える。
- 縦長のパッケージ画像は中央に置き、幅500〜700px、下端y=1850付近を目安にする。
- 画像の縦横比を保つ。実装では画像寸法から幅と高さを計算する。引き伸ばさない。
- 青枠コメントはx=80、y=470付近。2〜4行、黒い太字、白背景、青`#0000FF`の19pxの枠。
- ピンク枠コメントはx=80、y=950付近。青枠の下に配置し、必要に応じて画像の上部へ重ねる。枠色は`#E500FF`。
- 青枠が4行で縦に長くなるときは、ピンク枠を青枠の下端+32〜46pxへ下げる。
- 文字サイズは約96px、行高は約123px。左右の内側余白18〜24px。
- 白枠の横幅は文章から決める。短文を長方形いっぱいまで無理に広げない。
- 文字が収まらない場合は、まず改行と表現を直す。小さすぎる文字や画面外へのはみ出しで済ませない。

## 動きの基準

タイトルと順位・ゲーム名は、画面中央を中心に拡大・縮小して入る。30fpsで次の拡大率を1フレームずつ適用し、その後は1で静止させる。

```js
const zoomFrames = [1.25, 1.19, 1.075, 1, 0.9, 1.028, 1.1, 1.045, 0.95, 1];
const scale = zoomFrames[Math.min(localFrame, zoomFrames.length - 1)];
```

初期の約0.3秒を短い反動として見せる。長いふわふわした動きへ置き換えない。ゲーム画像はこの拡大縮小と別に扱い、下から約6フレームで入れる。初期移動量の目安は画像の高さ×1.08。文字と画像をひとつの平坦な画像にまとめない。

1項目の基本的な流れは、順位または紹介番号と名前→画像→青枠コメント→ピンク枠コメント→次の項目。コメントは短く切り替え、表示後は止めて読ませる。場面の境界はカットでつなぐ。ランキングと並列紹介で背景やアニメーションを作り直さない。

音声が未指定の試作は無音で作ってよい。その場合は無音だと明記する。音声付きの完成版を求められたら、各文の音声を用意して長さを測り、その長さから表示フレームを決める。名前の読み間違いを直し、前の項目の音声が次の順位へはみ出さないようにする。

生成音声に長い末尾の無音があれば、完全な無音だけを切って40ms程度残す。語尾や文中の間、声の速さは保つ。整えた音声の実測尺から表示時間を計算し、発話後の待ち時間を重複して足さない。次のコメントまで約0.1〜0.15秒、項目の切替まで約0.2〜0.25秒、最後は約0.1秒を初期目安にし、語尾が欠けていないか確認する。

SEを追加するときは、個別の音源ファイルと出所・利用条件を確認する。項目の開始・コメントの出現など、既存の表示キューに合わせて配置し、ナレーションより目立ちすぎない音量でミックスする。参考動画に声やBGMと一緒に入っている音を、そのまま独立したSEと扱わない。音源を特定できたものと、近い音で再現したものを区別する。

## 参考動画が渡された場合

参考動画の冒頭、順位が切り替わる瞬間、コメントの出現、終わり方を確認する。通常速度と連続フレームの両方を見る。背景、文字、画像、枠を別々の要素として観察する。

上の初期値は出発点。参考の書体、文字の幅、縁取り、余白、画像の大きさ、回転速度、数フレームの反動に合わせて修正する。見ていない動きを推測したときは、観察した値と区別する。

URLから取得できなければ、参考動画ファイルを受け取って続ける。アクセスできていない動画について「解析済み」「完全一致」と報告しない。

参考動画そのものを出力に貼り付けて完成扱いにしない。オリジナル版は台本と画像を差し替え、文字を編集可能なまま描画する。参考に含まれる映像・音声を公開用の素材一式へ無条件に同梱しない。

## 制作と確認

1. 入力JSONと画像を用意する。
2. Remotionで背景、見出し、画像、コメントを別レイヤーとして実装する。
3. 冒頭、各順位の名前表示、各コメント、最後の静止画を出す。
4. 文字の欠け、画像の縦横比、コメントと画像の重なりを確認して修正する。
5. MP4を書き出し、通常速度で動きと音声を確認する。
6. 3項目以上で内容を変えた作例を出す。ランキングと並列紹介のラベル・順番・読み上げが切り替わり、毎回コードを書き直さずに使えることを確かめる。

最終的にMP4、入力JSON、編集可能なソース、素材を保存する。使った画像の出所と生成した画像を区別してメモする。今回確認した項目数と文字量を伝え、未確認の用途まで動作保証を広げない。

## そのまま使う指示

```text
このSKILL.mdを読んで、ランキング動画を作ってください。
テーマは「ここにテーマ」。TOPは3です。
2ch系の話題を参考に、画像は実際のネット画像を基本にしてください。
紹介する順番、短い台本、使う画像を提案し、
内容が決まったら画像を用意してMP4まで書き出してください。
台本と画像を差し替えて、次の動画も同じデザインで作れる形にしてください。
```

順位のない紹介なら「ランキングではなく、順不同の5選にしてください」と指定する。

参考を使ってさらに合わせたいときは、Astraへ動画を渡して次のように依頼する。

```text
この動画を真似してください。
背景、文字のデザイン、画像の大きさ、コメントの枠、
表示タイミング、冒頭の反動まで見比べて近づけてください。
内容は添付した自分の台本と画像へ差し替えてください。
まず冒頭の見た目と動きを合わせ、その後に全編を仕上げてください。
```

音声や画像素材は、使う環境に合う利用条件を確認する。AquesTalkは[公式ライセンス](https://www.a-quest.com/licence.html)と[公式FAQ](https://www.a-quest.com/faq.html)を参照。
⑥ 動画を作った先に、収益の入口を持つ
動画が完成すると、それだけで満足しやすい。でも、僕はその後に何へつなぐかまで考えておきたい。
受託制作なら、お店の商品紹介や担当者の発信に使える動画として提案する。自分のチャンネルなら、視聴者が次に知りたいことへ案内する。
たとえば転職のジャンルなら、「面接でよく聞かれる質問3選」という動画を作る。
興味を持った人をプロフィールのリンクから、自分で作った転職サービスの比較記事へ案内する。その記事に、参加条件を満たしたアフィリエイト案件を載せる、という流れだ。
Shortsの説明欄やコメントに置いた通常のURLはクリックできない。プロフィールのリンクなど、実際に移動できる場所を使う。
A8.netもYouTubeでのアフィリエイト利用を案内している。メディア登録や案件ごとの条件を確認し、広告・PRであることがわかるように掲載する。
広告収益以外にも入口を持つと、YouTubeの広告単価や収益化条件への依存を減らせる。
YouTubeは2027年2月からの収益条件変更も案内している。Shortsの広告分配では、継続的な再生条件が導入される予定だ。条件は変わるので、広告収益だけを前提にせず、自分の商品や紹介したいサービスまで考えておくと使い道が広がる。
最初は好きなテーマでTOP3を一本。できたら台本や見せ方を変えて投稿し、視聴者の反応を次の一本に反映する。その先に、受託制作や集客にも使える形を育てていく。

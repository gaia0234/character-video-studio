# Knowledge Anime 編集室

今回の6場面を、Windowsのブラウザーから編集するためのローカルUIです。
キャラ・背景はカーノ音声修正版の素材を使用します。

## 起動

Windowsのデスクトップにある **Knowledge Anime Editor** をダブルクリックすると、
編集サーバーを起動してブラウザーを開きます。起動済みの場合は、そのサーバーを使います。
新しく開いたサーバー用のターミナルは、編集中は開いたままにしてください。
終了はサーバー用ターミナルで Ctrl+C。Codexの起動は不要です。

ショートカットは `scripts/install-editor-shortcut.ps1`、起動処理は
`scripts/start-editor-windows.ps1` にあります。現在のWSLディストリビューション
`Ubuntu-26.04` とこのプロジェクトのパスを使用します。

コマンドで起動する場合は、
WSL側のこのプロジェクトで実行します。

```sh
npm run editor
```

Windowsのブラウザーで **http://127.0.0.1:3210** を開きます。
サーバーを起動しているターミナルは開いたままにしてください。
終了はそのターミナルで Ctrl+C。次回も同じコマンドで起動できます。

## 編集から動画出力まで

1. 左の場面一覧から編集する場面を選びます。「前へ」「後ろへ」で順番を変えられます。
2. 右の入力欄で字幕・読み上げ文・声の速さ・間・キャラの大きさと位置を変更します。
3. **保存**で台本を保存します。字幕や配置はプレビューへすぐ反映されます。
4. 読み上げ文・話すキャラ・声の速さを変えたら、**音声を更新**で反映します。
5. **動画を書き出す**でMP4を生成し、**MP4をダウンロード**でWindowsへ保存します。

音声更新・動画出力のボタンは未保存の編集も先に保存します。
処理中は編集をロックし、進捗を表示します。処理中に再読み込みしても進捗を再表示します。
読み上げを変更した場面は、音声を更新するまでプレビューの該当音声を再生せず、動画出力も止めます。
字幕だけの変更では音声更新は不要です。

字幕と読み上げ文は独立しています。例えば字幕は「１：１」、読み上げ文は「いち対いち」と入力できます。
セリフ後の間は0.3秒以上。情報の場面では「情報を見る時間」も追加できます。
尺は音声の実測時間と間から自動計算するので、声を遅くしても途中で切れません。
再生ボタンで声を聴き、字幕・キャラの位置をプレビューで確認してください。

## 保存先

- 編集内容の正本：`src/data/editor-project.json`
- 生成した音声：`public/audio/editor/<処理ID>/`
- 動画・使用台本・検査結果：`output/editor/jobs/<処理ID>/`
- 保存前の台本バックアップ：`.editor/backups/`

音声生成処理は正本を入力として使うため、編集した字幕・速度・間・配置が初期値へ戻ることはありません。
変更のない音声は再利用し、新しい音声と動画は処理IDごとに保存します。
従来の無音試験・音声試験のJSONとMP4は別の制作データです。

複数のタブで編集した場合、古い台本の上書きは拒否します。更新されている旨が表示されたら、
未保存の文章を手元に控えてから画面を再読み込みしてください。

## 環境

Node.js・Python・VOICEVOX Coreは現在のWSL環境を使用します。
音声クレジット・利用規約の確認状況は [音声試験の記録](../sources/character-dialogue-voice.md) を参照してください。
初版の調整方法は入力欄とスライダーです。

別のChromeを使う場合は、起動前に実行ファイルを指定します。

```sh
KNOWLEDGE_EDITOR_BROWSER=/absolute/path/to/chrome npm run editor
```

現在の既定値は、この環境で検証済みのPlaywright Chromiumのパスです。
サーバーはローカルの127.0.0.1に接続します。公開サーバーとしての運用は想定していません。
ソースコードを変更した場合はサーバーを再起動して画面を再読み込みします。

## 開発時の通し検証

実際の台本を変更しないよう、試験用コピーと別ポートを使用します。
まず `npm run editor` でビルドし、別のターミナルで次を実行します。

```sh
mkdir -p output/editor/verification
cp src/data/editor-project.json output/editor/verification/project.json
KNOWLEDGE_EDITOR_PORT=3211 KNOWLEDGE_EDITOR_PROJECT=output/editor/verification/project.json node scripts/editor-server.mjs
```

さらに別のターミナルで `npm run verify:editor` を実行します。
試験用の3211ポートへ接続し、入力拒否、保存と再読み込み、並び替え、
読み上げ変更後の音声更新、更新中の操作拒否、書き出しとダウンロードを確認します。
試験結果と動画は `output/editor/verification/` に保存します。
完了後は3211ポートの試験用サーバーをCtrl+Cで終了します。
